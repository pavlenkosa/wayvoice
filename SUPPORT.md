# Support

Start with [getting started](docs/getting-started.md), [troubleshooting](docs/troubleshooting.md) and [desktop support](docs/desktop-support.md).

For reproducible bugs and feature requests, use [GitHub Issues](https://github.com/pavlenkosa/wayvoice/issues) and the existing issue templates. Include version/commit, package type, distribution, desktop and Wayland/X11 session, engine/model/device, steps, expected behavior and actual behavior. For insertion problems, say whether the recognized text reached the clipboard.

Review Diagnostics before attaching a report. Remove dictated text, audio, usernames, paths, tokens and other personal information you do not want public. Do not upload a recording unless you explicitly choose to share it and have permission.

Use [SECURITY.md](SECURITY.md) for vulnerabilities; do not disclose exploits or credentials in a public issue. There is no guaranteed response time or claimed private reporting channel beyond what GitHub actually exposes. Discussions may be enabled later; Issues remain the public support route.
