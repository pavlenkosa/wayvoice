# WayVoice 0.8.3

Alpha release candidate. Local voice input for Linux and Wayland; the default recognizer remains Faster-Whisper.

## Highlights

- Fix AppImage CI builds on runners using UID 1001 by provisioning the host UID/GID in both container images. D-Bus and GTK checks retain nonroot execution.
- This candidate includes the 0.8.0 feature set. The 0.8.1 and 0.8.2 tags referenced code still versioned 0.8.0 and failed validation; 0.8.3 restores consistent release metadata without moving those tags.

- Choose a prepared recognition model and language directly on Home. Selection is idle-only, preserves unsaved Settings drafts, and applies to the next dictation.
- Each recording keeps its own settings through recognition and text delivery. Recording-stop failures and timer exhaustion unwind safely.
- Experimental CPU Parakeet TDT 0.6B v3 supports automatic detection across 25 model languages. Preparation is explicit and checksum-verified; recording never downloads weights.
- AppImage replaces the experimental Flatpak distribution. DEB and RPM remain available. Update dialogs retain their usable minimum size across client-side decoration styles.

## Compatibility

Native Debian/Ubuntu and Fedora 44 packages retain systemd user services and direct-process fallback. AppImage targets x86_64 Linux with glibc 2.39 or newer and bundles Python 3.12, GTK/libadwaita and recognition runtimes. It uses direct processes and normal user configuration/model/socket paths, so quit any existing native WayVoice before switching.

Automated widget checks cover GTK, including Ubuntu 24.04/Xvfb. Such tests do not verify live GNOME/Wayland microphone capture, focus, insertion or global shortcuts. Complete installed AppImage desktop/FUSE acceptance and Parakeet RU/EN quality/performance comparison remain open; KDE/wlroots and other RPM distributions are not validated for this candidate.

## Downloads

Candidate builds produce an amd64 DEB, Fedora 44 x86_64 RPM, x86_64 AppImage and source archive. Verify the extracted assets with `sha256sum --check SHA256SUMS`. AppImage is executable after `chmod +x`; use `--appimage-extract-and-run` where FUSE is unavailable. No separate GNOME Flatpak runtime is required. These checksums check integrity relative to the release; they are not independent publisher signatures.

This candidate follows the existing alpha policy: publication, when explicitly approved, is a GitHub Pre-release rather than Latest. Alpha packages and AppImage updates are installed manually; the native updater follows stable releases only.

## Known limitations

Automatic paste depends on the desktop and host permissions; successful recognition still leaves text in the clipboard when insertion is unavailable. AppImage shares settings and the daemon socket with native WayVoice and is not a sandbox. Keep its file path stable for configured shortcuts; quit the daemon before replacing the executable.

Parakeet runs a new CLI process for each request and is not kept warm. Its first preparation currently has a busy state without progress/cancel controls, and window close waits for preparation to finish or fail. No speed or accuracy advantage is claimed. Real microphone/insertion and installed package update/recovery acceptance are not established solely by automated tests. Flatpak is no longer built or published from 0.8.0.
