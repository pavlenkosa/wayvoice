# WayVoice 0.9.0 Beta

A GNOME-native, Linux-first dictation beta focused on understanding and verifying text delivery. This is a GitHub prerelease, not a stable release.

## Highlights

- Recognition readiness and delivery prerequisites are displayed separately. Passive integration checks explain missing tools, unreachable helpers and shortcut mismatches without delaying routine status updates.
- An optional paste check sends a neutral multilingual string after a cancellable five-second countdown. Choose Standard, Terminal or Clipboard without changing saved preferences, then explicitly confirm receipt. Clipboard replacement is explained before starting.
- Home has fewer duplicated details, narrow windows use bottom navigation, and keyboard actions, persistent errors and accessible language/mode controls are improved. All ten interface catalogues include the new flow.
- AppImage includes the paste client; a host helper with uinput access remains required for automatic insertion. Clipboard fallback remains available. Cancellation, owned sockets, preparation cleanup and text-processing safeguards are retained.

## Compatibility

Linux is the supported platform, with GNOME/Wayland the primary integration target. DEB/RPM retain systemd user services and direct-process fallback. AppImage targets x86_64 and glibc 2.39 or newer. Initial runtime/model preparation is explicit; ordinary local dictation does not download model weights.

A real automatic paste into a separate controlled GTK field was observed with target focus retained and explicitly confirmed by the user. This does not establish the complete editor/browser/terminal and EN/RU matrix for both native packages and AppImage. Faster-Whisper remains the default; CPU Parakeet remains experimental.

## Downloads

The release pipeline prepares an amd64 DEB, Fedora 44 x86_64 RPM, portable x86_64 AppImage and source archive. Only assets actually attached to the release are available. Verify downloads against the release's SHA256SUMS; these checksums establish integrity relative to that release, not independent publisher authentication.

Beta is marked Pre-release and not Latest. Install beta updates manually: the native updater follows stable releases only. Do not replace an existing image while its processes are running.

## Known limitations

Complete installed GNOME/Wayland editor/browser/terminal acceptance in explicitly selected EN/RU layouts, installed upgrades and recovery, FUSE launch and auditory/onscreen-keyboard acceptance remain open. KDE/wlroots support is not established by the automated suite. No comparative advantage over Handy is claimed.

Automatic paste requires host integration and permissions. Native packages and AppImage share the normal configuration, model cache and daemon socket; quit existing WayVoice processes before switching installations. CPU Parakeet is one-shot, with preparation progress/cancellation controls and RU/EN comparative acceptance still open.

The pinned static AppImage runtime's corresponding-source and relinking evidence remains unresolved. AppImage publication is blocked until that evidence is completed; a successful runtime smoke test does not resolve it.
