# WayVoice 0.8.4

Alpha release candidate focused on reliable local dictation, cancellation and recovery. Faster-Whisper remains the default recognizer; CPU Parakeet remains experimental.

## Highlights

- Cancellation and recognition timeouts no longer wait indefinitely for a detached external-command descendant that retains an output pipe. Local worker responses have bounded size and cumulative control-request deadlines.
- Temporary recordings now live in private, process-owned sessions. Cleanup skips active sessions and files whose ownership cannot be verified. Hand-edited recording limits above 24 hours are refused before the microphone opens.
- Opening an updated interface waits for model downloading or warming before recovering an older daemon version. Model deletion reports reclaimed space from interrupted downloads and removed metadata accurately.
- Dependency installation retains the system's standard administrator authentication prompt. Regression checks now exercise the intended failure paths, with improved isolation and substantially shorter local GTK test runs.

## Compatibility

DEB and RPM retain systemd user services and direct-process fallback. The portable x86_64 AppImage targets glibc 2.39 or newer and bundles Python 3.12, GTK/libadwaita and local recognition runtimes. Model preparation remains explicit; ordinary local recognition does not download weights.

Automated GTK tests and missing-GTK/headless checks verify different supported test environments. They do not establish live GNOME/Wayland microphone, focus, paste, global-shortcut or FUSE acceptance. Installed package upgrade/recovery and Parakeet RU/EN comparative quality/performance remain open.

## Downloads

Candidate builds produce an amd64 DEB, Fedora 44 x86_64 RPM, experimental x86_64 AppImage and source archive. Use the matching SHA256SUMS file to verify release assets. Checksums provide integrity relative to the release, not independent publisher authentication.

The existing alpha policy is unchanged: an approved publication is a GitHub Pre-release, not Latest. Alpha native packages and AppImage updates are installed manually; the native updater follows stable releases only.

## Known limitations

Automatic paste still depends on desktop integration and host permissions; clipboard delivery remains available when insertion cannot be used. AppImage shares normal configuration, model cache and the daemon socket with native installations. Quit existing WayVoice processes before switching installations or replacing the image.

Old WAV files in the shared temporary directory are deliberately excluded from automatic cleanup because their provenance cannot be established. CPU Parakeet remains a one-shot recognizer without preparation progress/cancel controls; no speed or accuracy advantage is claimed.

Portable-runtime corresponding-source and relinking verification remains pending; AppImage publication is blocked until that distribution evidence is complete. Live desktop and installed-package acceptance are also not implied by passing automated tests.
